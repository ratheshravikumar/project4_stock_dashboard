# project4_stock_dashboard

# 📈 Real-Time Stock Market Dashboard

A simple stock dashboard built using **Python + Streamlit + ML-style indicators**.

---

## 🚀 Features

* Live stock data (Yahoo Finance)
* Interactive charts
* Moving Averages (MA20, MA50)
* Trend detection (Bullish / Bearish)

---

## ⚙️ Installation

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the App

```bash
streamlit run stock_dashboard.py
```

---

## 📊 Example Symbols

* AAPL (Apple)
* TSLA (Tesla)
* INFY.NS (Infosys - India)
* TCS.NS (TCS)

---

## 🧠 ML Concept Used

* Moving Average Trend Analysis
